# Tríptico PNL (libro interactivo)

Tríptico de *Introducción a la PNL* (O'Connor y Seymour) para Sistemas Colaborativos, UTP.

- `index.html`: libro con efecto de pasar página (en celular, una página; en pantalla ancha, dos). Funciona sin conexión a otros sitios: la librería StPageFlip (licencia MIT) va incluida en el archivo.
- `paginas/`: las seis páginas del tríptico.
- `triptico-pnl-celular.pdf` y `triptico-pnl-imprimible.pdf`: descargas.

## Publicar con GitHub Pages

1. Sube todo el contenido de esta carpeta a la raíz de un repositorio público.
2. Ve a **Settings → Pages**, elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**, y guarda.
3. La dirección queda como `https://USUARIO.github.io/REPOSITORIO/`. El QR del Prezi debe apuntar ahí.
